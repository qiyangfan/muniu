# ADR-0014:同构直通路由——协议平等的 wire 侧落地

- 状态:已接受(2026-10-11;owner「我想要原生版」+「能直连就直连」+ 学习项目框架三次裁决驱动)

## 决策

入站协议与候选适配器的**原生协议一致**时,该次尝试走**同构直通**:出站 wire 为客户端原始字节(仅 model 字段原位手术 + 鉴权头/URL 注入),响应/流式事件/错误信封原样透传——零翻译、零字段丢失;翻译只属于跨协议对。

1. **协议平等原则(立法基线)**:chat 不是第一优先级协议。wire 路径永远优先原生直通;canonical 在控制面的**键载体**(指纹/计数)不含语义、可替换,不构成特权;控制面的**操作表示**(参数干预/缓存体)必须协议中立——缓存侧由本 ADR 双存消除,治理/插件侧以声明制零损失保证兜底(见 4)。
2. **N+M 保持,同构对加直通车道**:pairwise 直译矩阵否决(N×M 维护面,ADR-0003 同款论证);跨协议对保留经测试冻结的组合翻译。声明粒度因协议而异、原则同一:messages=`adapter: anthropic`(适配器类型即声明,经 `NativeProto()` 协议身份自述);responses=`providers[].native_responses` 显式声明(声明制实证:百炼 responses 端点多轮回放四路径全 400,「OpenAI 兼容」≠「responses 端点可用」,自动探测会让可用流量倒退);embeddings=`EmbeddingPreparer` 能力接口(先例)。
3. **有状态粘性路由收编 v1**(owner 学习项目框架裁决:需求触发线在无需求方框架下构造上永不触发,延后即永不):`previous_response_id` 在原生 lane 放行——provider 级亲和表(进程内 TTL+LRU;集群共享后端按 ADR-0008 复用登记,未配共享=实例内粘性)约束粘性路由(候选域收缩至亲和 provider,域内 failover 照常,跨 provider 换道不发生——服务端状态定向单上游的物理约束);`GET /v1/responses/{id}` 亲和已知代理转发、未知恒 404 自解释;亲和未知自解释降级禁盲发;状态请求旁路语义缓存;翻译路径维持拒绝;DELETE 代理登记 backlog。
4. **回落纪律与治理裁决权**:治理/插件改写 canonical 的任何干预使原始体失效 → 该 attempt 回落翻译路径(路由决策非错误:不计失败、不动 key 健康度、结构化日志留痕)。**治理必须对直通 wire 有裁决权**:翻译器静默丢弃的参数(top_k/metadata 等)不在 canonical 中,直通 attempt 以原始体同规则评估治理,干预即回落——约束在两条路径上等价可执行。今天的零损失保证:治理按 (provider, model) 声明制、插件按租户启用,不声明/不启用则回落永不发生。姊妹变更「协议中立干预」(约束 IR + 每协议 emitter)排入作品路线图;插件 ABI 维持 canonical + 回落边界(复杂度/收益比的显式技术选择,非需求缺失)。
5. **惰性拒绝**:含不可翻译内容块(image 等)的请求不再一律边缘即时 400——别名含直通资格候选时先按直通服务(多模态原生支持);仅当翻译路径实际被需要时升格既有 400;无直通候选别名行为逐字节不变。bridgegate 随之收窄:工具多轮豁免仅作用于翻译路径。

## 备选与否决

- **N×M pairwise 直译**:维护灾难 + 零增量保真收益(转换是结构性的,经 canonical 的组合翻译结果同构)。
- **给 Prepare 加模式参数**:污染全部适配器签名;可选能力接口(`NativePreparer`,与 `EmbeddingPreparer` 同款)零侵入。
- **responses 自动探测**:可用流量倒退(百炼实证),声明制 = 运维知识显式化。
- **开关式放行(不做亲和)**:id 定向单上游,盲发引发 404 换道级联,比显式拒绝更不诚实。
- **有状态仍延后**:触发线在无需求方框架下不可触发,与章程「完整度优先」冲突。

## 后果

- `internal/protocol` 双形态翻译结果(canonical 单源不变 + 原始体保留 + 失格标记);`internal/adapter` NativePreparer/NativeFetcher 可选能力接口;`internal/proxy` 每 attempt 路径判定 + writer 模式位 + 亲和表;`internal/config` `providers[].native_responses`(缺省 false,语义缓存表迁移 0008 增直通双存列)。
- 语义缓存双存:canonical(跨协议命中,既有等价性不变)+ 原生体+协议标签+表单标记(同构命中零翻译恒等回放);canonical 衍生失败仅降级为跨协议不可命中。
- 已知登记:翻译路径的 `message_start.usage.input_tokens` 恒 0 偏差在直通路径自然消失;国产分支端点 anthropic 形态差异(quirk 缺位)待真 key 冒烟按 quirk 纪律回填;治理/插件协议中立化为具名路线图项(姊妹变更)。
