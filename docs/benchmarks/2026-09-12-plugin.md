# 插件运行时压测对照(2026-09-12,ADR-0011 任务 6.2)

## 目的

验证插件性能红线(spec「性能护栏与可观测」):**插件禁用时转发主路径无可测量新增开销;
启用时开销有界、可观测**。

## 方法

进程内基准(`internal/proxy/plugin_hook_test.go`),fake 上游(本机回环,非流式单响应),
M1 Pro / darwin arm64 / go1.27.1;`go test -bench BenchmarkPluginHook -benchmem`。
两形态同剧本同路由:

- **禁用态**:`proxy.Config.Plugins = nil`(无插件设施,等价既有主路径);
- **启用态**:注册 1 个 pass 插件(ABI v0 fixture,每请求一次 wazero 实例池复用调用)。

## 结果

| 形态 | ns/op | B/op | allocs/op |
|---|---|---|---|
| 禁用(nil) | 216,131 | 35,456 | 321 |
| 启用(pass 插件) | 220,630 | 36,579 | 344 |
| **增量** | **+2.1%** | +1,123 B | +23 |

## 解读

- **禁用态零回退**:`Plugins == nil` 分支零分配短路(一次指针判空),与插件设施引入前的
  路径逐字节相同;表中禁用行即既有基线形态。
- **启用态开销有界**:每请求 +23 allocs(实例池复用下的单次 wasm 调用 + 输入拷贝)。
  相对全请求路径(http + 解析 + 计量,~216μs)占 4.5μs;对照压测总基线
  (峰值 38,498 rps、首字节 p50 1.15ms,docs/benchmarks/2026-09-10.md)约折损 <5%,
  不改数量级。
- **真实插件实测**:pii-masker(Rust wasm32-unknown-unknown,3 条正则 + serde_json
  重序列化)全流程冒烟中单请求插件链路 <5ms(直方图 le="5" 命中,见 HANDOFF 验收记录 22)。

## containment 表现

故障注入测试(`internal/plugin/runtime_test.go`)覆盖四态:死循环超时(80ms 上限,
epoch 中断)、trap、越界写(超内存)、proc_exit——网关进程全部存活,后续请求由池内
新实例正常服务;fail_open 配置下 containment 放行原请求(审计 + 指标留痕)。

## 局限

- 本对照为进程内基准(fake 上游),非全链路网络压测;启用形态的外部吞吐对照
  (oha)可在灰度期按 `scripts/bench/run_oha.sh` 复跑,预期结论一致(插件链路 μs 级)。
- 单 pass 插件形态;多插件链式启用按插件数线性叠加。
