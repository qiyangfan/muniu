# 集群语义:每实例分片状态与集群口径

> ADR-0005 双形态(standalone / cluster)与 ADR-0008(实例级自治 + 控制面全局预算)的
> 状态归属显式化。原则:**副本无状态化 = 可随时替换;但"无状态"不等于"零本地状态"——
> 本地状态只允许两类:可丢失的(缓存/观测)与可重放的(计量缓冲)**。

## 每实例本地状态盘点

| 状态 | 归属 | 实例间关系 | 集群口径 |
| --- | --- | --- | --- |
| key 池(三态/EMA 健康度) | 运行态 | 各实例独立观测同一批上游 key:某实例判冷却、另一实例可能仍放行 | **接受分歧**——健康度是实例对上游的本地贝叶斯,上游真实反馈(429/401)是最终裁判;key 值同源(env/控制面),无数据分歧 |
| RPM 令牌桶 | 限流 | inmem 后端:实例独立计数,N 副本 ≈ ×N;**redis 后端(cluster-ratelimit-shared-view,落地中):共享视图,×N 消除** | ADR-0008 修订(2026-09-13):限流是漏桶不是闸门——需要共享视图,不是强一致;redis 不可达降级回实例自治并告警 |
| TPM 滑动窗口 | 限流 | 同 RPM 后端形态(窗口内 token 计数;redis 后端为原子 INCR+TTL 窗) | 同 RPM 行(ADR-0008 修订);全局预算以控制面聚合计量事后校准 |
| 语义缓存(HNSW+LRU) | 加速 | 实例本地键空间,天然按内容哈希分片;命中率随副本数稀释 | 正确性不依赖缓存(TTL + "宁缺勿错"准入兜底);跨副本失效不做 v1 |
| 计量缓冲表(SQLite) | **钱** | 失败缓冲,恢复按序续传,幂等键去重 | 可重放类本地状态的唯一合法形态;续传目标为锦官 ingest(权威侧幂等),本地 usage_logs 始终保留 |
| 控制快照(价目/拓扑/吊销/租户配额/策略包) | 只读 | 统一快照条件请求 + RSA 验签;失败保持 last-known | 安全类缺失 fail-closed;非安全类 last-known 标 stale;版本单调防回退 |

## 权威归属(谁说了算)

| 数据 | 权威 | 副本视角 |
| --- | --- | --- |
| 用户/钱包/账本 | 控制面(PG) | 副本不持有,仅 ingest 上报用量 |
| 价目 | 控制面下发(YAML 静态兜底) | 快照收敛,managed 本地只读,失联保持 last-known |
| key 与吊销 | 控制面签发/吊销 | 自校验 key 离线验真;吊销经版本快照收敛(窗口上界可配) |
| 拓扑(providers/routes) | 控制面下发(YAML 静态兜底) | 快照原子热替换;managed 忽略 SIGHUP;校验失败保持旧快照(3.3) |

## 负载均衡口径

- **无亲和要求**:请求状态(路由/限流/计量)全部在请求上下文与实例本地,任一副本可服务任一请求;流式请求的连接内亲和由 LB 的 TCP 会话天然保证。
- 健康检查:`GET /healthz` 轻量探活;注册心跳携带真实健康事件,不伪造 ready。
- 容量口径:压测基线(docs/benchmarks/)为单实例数字;线性扩展假设成立(实例间无协同),共享上游配额才是全局瓶颈。
