# 集群语义:每实例分片状态与集群口径

> ADR-0005 双形态(standalone / cluster)与 ADR-0008(实例级自治 + 控制面全局预算)的
> 状态归属显式化。原则:**副本无状态化 = 可随时替换;但"无状态"不等于"零本地状态"——
> 本地状态只允许两类:可丢失的(缓存/观测)与可重放的(计量缓冲)**。

## 每实例本地状态盘点

| 状态 | 归属 | 实例间关系 | 集群口径 |
|---|---|---|---|
| key 池(三态/EMA 健康度) | 运行态 | 各实例独立观测同一批上游 key:某实例判冷却、另一实例可能仍放行 | **接受分歧**——健康度是实例对上游的本地贝叶斯,上游真实反馈(429/401)是最终裁判;key 值同源(env/控制面),无数据分歧 |
| RPM 令牌桶 | 限流 | 实例独立计数,N 副本 = 实际放行上限约 ×N | ADR-0008 裁决:实例级自治 + 控制面全局预算纠正;分布式强一致限流明确不做 |
| TPM 滑动窗口 | 限流 | 同上(窗口内 token 计数本地累计) | 同上;全局预算以控制面聚合计量事后校准 |
| 语义缓存(HNSW+LRU) | 加速 | 实例本地键空间,天然按内容哈希分片;命中率随副本数稀释 | 正确性不依赖缓存(TTL + "宁缺勿错"准入兜底);跨副本失效不做 v1 |
| 计量缓冲表(SQLite) | **钱** | 失败缓冲,恢复按序续传,幂等键去重 | 可重放类本地状态的唯一合法形态;续传目标为控制面 ingest(权威侧幂等) |
| 配置快照(拓扑/价目/吊销) | 只读 | 控制面拉取收敛,ETag 条件请求;失败保持旧快照 | 收敛窗口有界可配置(poll_interval_sec);吊销版本单调防回退 |

## 权威归属(谁说了算)

| 数据 | 权威 | 副本视角 |
|---|---|---|
| 用户/钱包/账本 | 控制面(PG) | 副本不持有,仅 ingest 上报用量 |
| 价目 | 控制面下发(YAML 静态兜底) | 拉取收敛,失联保持最后快照 |
| key 与吊销 | 控制面签发/吊销 | 自校验 key 离线验真;吊销经版本快照收敛(窗口上界可配) |
| 拓扑(providers/routes) | 控制面下发(YAML 静态兜底) | 热替换原子生效;校验失败保持旧快照(3.3) |

## 负载均衡口径

- **无亲和要求**:请求状态(路由/限流/计量)全部在请求上下文与实例本地,任一副本可服务任一请求;流式请求的连接内亲和由 LB 的 TCP 会话天然保证。
- 健康检查:`GET /actuator` 类活性以 `/metrics`(启用时)或 TCP 探针为准;不提供专用 healthz 端点(v1)。
- 容量口径:压测基线(docs/benchmarks/)为单实例数字;线性扩展假设成立(实例间无协同),共享上游配额才是全局瓶颈。
