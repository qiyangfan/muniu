# data-plane-state-sync Specification

## Purpose
无状态副本的状态分层:自校验 key 离线验真 + 配置源双驱动(文件/控制面),使网关副本不持有权威状态即可水平扩展;standalone 单机形态行为保持不变。

## Requirements

### Requirement: 自校验 API key

系统必须 (MUST) 支持 HMAC 签名形态的平台 key(载体含签发方标识、用户/租户标识、过期时间与签名),网关必须 (MUST) 能在不查询任何数据库的情况下验证其真实性与有效期;吊销必须 (MUST) 经版本化同步收敛(控制面递增版本号,网关拉取吊销名单/版本快照),收敛窗口必须有界且可配置;现有查库 key(mk- 形态)必须 (MUST) 继续支持,两种形态并存且 standalone 默认行为不变。

#### Scenario: 离线验真
- **WHEN** 携带合法平台 key 的请求到达任一网关副本,且该副本与控制面断连
- **THEN** 请求正常通过鉴权并转发计费(签名与有效期本地可验)

#### Scenario: 过期与篡改拒绝
- **WHEN** 平台 key 被篡改任一字符或已过有效期
- **THEN** 请求被 401 拒绝,不产生上游调用与计量

#### Scenario: 吊销收敛有界
- **WHEN** 控制面吊销某平台 key 并递增版本
- **THEN** 全部副本在配置的同步窗口内拒绝该 key,窗口上界可配置且有文档默认值

### Requirement: 配置源双驱动

providers、model_routes、pricing 三类拓扑必须 (MUST) 支持「本地文件(现状)」与「控制面版本化拉取」两种配置源;两源均必须 (MUST) 经同一套校验后原子热替换运行态目录(在途请求用旧快照完成,新请求即用新快照);版本化拉取必须 (MUST) 支持条件请求(未变更不传输)与变更校验和;控制面不可达时必须 (MUST) 保持最后一次成功快照继续服务(降级可用),启动时无任何快照且控制面不可达必须 (MUST) 启动失败(fail-fast)。

#### Scenario: 热更新无重启
- **WHEN** 控制面变更渠道拓扑并递增版本,网关完成一轮拉取
- **THEN** 新请求按新拓扑路由计价,服务全程无重启、在途请求不受影响

#### Scenario: 控制面失联降级
- **WHEN** 控制面持续不可达
- **THEN** 网关以最后一次成功快照继续转发与计量,并按固定间隔告警日志暴露降级状态

#### Scenario: 快照损坏拒绝应用
- **WHEN** 拉取的快照未通过校验(校验和不符或结构非法)
- **THEN** 丢弃该快照、保持旧快照、告警,绝不放行脏配置

### Requirement: 形态等价与单机不回归

standalone 形态(文件配置源 + 本地计量汇)的行为必须 (MUST) 与引入平台能力之前逐字节等价(请求/响应/计量行/管理 API);平台 key、配置源、计量汇均为可选装配,未配置时必须 (MUST) 完全不启用。

#### Scenario: standalone 零回归
- **WHEN** 以纯文件配置源 + 本地计量汇运行既有 E2E 用例集
- **THEN** 请求/响应/计量行/管理 API 行为与引入平台能力之前逐字节等价
